## Project Overview
A Java Spring Boot application designed to manage and expose CrossFit "Workout of the Day" (WOD) data via a REST API. This project is built using a structured package approach under `com.internship.crystal`.

## Technologies Used
* **Java:** Version 17 (OpenJDK)
* **Framework:** Spring Boot
* **Build Tool:** Maven 3.9.2
* **Version Control:** Git

## Setup Instructions
1. Open your terminal (or IntelliJ Terminal).
2. Clone the repository:
   `git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git`
3. Navigate to the project folder:
   `cd YOUR_REPO_NAME`
4. Run the application using the Maven Wrapper:
   `./mvnw spring-boot:run`

## Usage
Once the server is running, the application starts on port `8080`.
* **Basic Endpoint:** Access `http://localhost:8080/hello` to verify the server is live.

## Project Structure
The core logic of this application is located in the `com.internship.crystal` package.
